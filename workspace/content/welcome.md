## The theme is a file you can open

Click `themes/lossless.css` in the Files rail. Change a value. This document
restyles as you type — no reload, no rebuild.

> [!note] It persists
> The theme lives in the **workspace**, beside your documents, not inside any
> one of them. Start a new document tomorrow and it is still here.

> [!warning] Brought in, not authored
> This file was copied from flave's own splash — a real, finished theme rather
> than a blank stylesheet. Any block of CSS custom properties is already a flave
> theme, so a `theme.css` lifted from an existing site works untransformed.

| Folder | Persists | Holds |
|:-------|:--------:|:------|
| `themes/`     | yes | named `.css` files |
| `components/` | yes | trigger-packs |
| `content/`    | per-document | the prose |
